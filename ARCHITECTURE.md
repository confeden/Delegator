# Архитектура Delegator

## Установленная структура

```text
delegator.exe
  -> запускает и контролирует скрытый delegator-core.exe
  -> управляет треем и нативным GUI
  -> шифрует ключи провайдеров через DPAPI текущего пользователя
  -> устанавливает и удаляет инструкции для IDE

delegator-core.exe
  -> локальный FastAPI на 127.0.0.1:1380
  -> сессии, сообщения и задачи в SQLite
  -> вызывает runtime\ai-delegate.cmd

runtime\ai-delegate.cmd
  -> маршрутизация, планирование, параллелизм, retry и verify
  -> gemini-delegate.ps1: прямой Google models.generateContent
  -> opencode-delegate.ps1: OpenCode CLI или прямой OpenRouter API
```

Изменяемые данные и секреты находятся в AppData текущего пользователя, а не в каталоге программы. Поэтому обновление заменяет бинарники и runtime, не перезаписывая конфигурацию.

## Границы доверия

- Ключи вводятся только через GUI Delegator.
- `config.json` содержит DPAPI-шифротекст, а не открытые ключи.
- Google и OpenCode/OpenRouter поддерживают несколько включаемых и удаляемых аккаунтов.
- Расшифровка выполняется только runtime-скриптом текущего пользователя непосредственно перед запросом.
- Системные Google-переменные и учётные данные других приложений игнорируются.
- Core слушает только loopback-интерфейс.
- IDE hooks не содержат ключей: только установленный путь и контракт использования.

## Маршрутизация моделей

Gemini ограничен тремя alias: `gemini-pro-latest`, `gemini-flash-latest` и `gemini-flash-lite-latest`. Runtime дополнительно проверяет, что запрошенная модель включена в GUI.

Модели `opencode/*` запускаются через установленный OpenCode CLI. Модели `openrouter/*` вызываются напрямую и используют один из включённых DPAPI-ключей. Список, выбранный в GUI, является обязательным allowlist для runtime.

## Диагностика зависимостей

GUI проверяет наличие `opencode.cmd` или `opencode.exe` в `PATH`. Если выбрана хотя бы одна модель `opencode/*`, но CLI отсутствует, вкладка **Модели OpenCode** получает жёлтую рамку и показывает инструкцию установки. Для `openrouter/*` аналогично подсвечивается вкладка **API-ключи**, если нет включённого ключа.

## Жизненный цикл

Обычный запуск показывает панель. `--background` создаёт приложение в трее со скрытым окном. Закрытие панели скрывает её; команда выхода из трея завершает GUI и дочерний Core. `--remove-hooks` используется деинсталлятором без запуска GUI.

При старте существующий процесс на порту 1380 принимается только тогда, когда health-ответ подтверждает `delegator-core` и тот же установленный `runtime\ai-delegate.cmd`.

## Переносимость

Установщик использует стабильный каталог текущего пользователя и формирует IDE-пути на целевом ПК. Он не содержит исходный checkout, Python-окружение, пользовательскую конфигурацию или дерево `.codex` компьютера сборки. Системный Python не нужен. Единственная дополнительная зависимость для моделей `opencode/*` — OpenCode CLI; она явно диагностируется в GUI.
