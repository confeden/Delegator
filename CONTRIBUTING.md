# Участие в разработке

## Подготовка окружения

На компьютере сборки требуются:

- Windows 10 или 11 x64;
- стабильный Rust toolchain;
- Python 3.12 или новее;
- PowerShell 5.1 или новее.

```powershell
python -m venv .venv312
.\.venv312\Scripts\python.exe -m pip install -e .
cargo test --locked
```

Сборка автономного установщика:

```powershell
.\build-installer.ps1
```

Скрипт устанавливает закреплённые зависимости PyInstaller, проверяет контрольную сумму Inno Setup, скрывает локальные build-пути, запускает тесты и записывает результат в `dist\`.

## Pull request

- Не добавляйте ключи, данные аккаунтов, приватные запросы и неочищенные журналы.
- Не копируйте в репозиторий файлы из `%APPDATA%`, `%LOCALAPPDATA%`, `.codex`, `.gemini` и профилей IDE.
- Сохраняйте выбор моделей GUI как главный allowlist runtime.
- Не добавляйте fallback к системным Google-переменным.
- Добавляйте тесты для миграций конфигурации, DPAPI, маршрутизации, зависимостей и темы.
- Перед commit запускайте `scripts\audit-release.ps1`.

Установщики, `target\`, виртуальные окружения, базы, журналы и локальная конфигурация намеренно исключены из Git.
