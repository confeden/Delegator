# Политика безопасности

## Поддерживаемая версия

Исправления безопасности выпускаются для последней beta-сборки `0.2.x`.

## Сообщение об уязвимости

Используйте приватное сообщение GitHub: **Security → Advisories → New draft security advisory**. Не создавайте публичный issue для проблем с ключами, DPAPI, выполнением команд, установщиком или запросами провайдера.

Не отправляйте:

- открытые API-ключи и токены;
- `%APPDATA%\Delegator\DelegatorWin\config\config.json`;
- базы Delegator, приватные prompts и неочищенные журналы;
- учётные данные других IDE.

Укажите версию Delegator и Windows, шаги воспроизведения, возможное влияние и очищенные доказательства.

## Модель хранения ключей

Delegator хранит ключи Google и OpenCode/OpenRouter как DPAPI-шифротекст текущего пользователя. Бинарники и исходные релизы не должны включать AppData-конфигурацию. Провайдер Google не должен использовать `GEMINI_API_KEY`, `GOOGLE_API_KEY`, CLI-профили или открытые файлы ключей.

Ключи не выводятся в журналы и передаются только соответствующему HTTPS endpoint. Удаление аккаунта из GUI удаляет его шифротекст из конфигурации.
